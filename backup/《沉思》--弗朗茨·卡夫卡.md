# 卡夫卡的遗嘱
#### ——由于它们已经存在过，我不会阻止任何人得到它们，若他们有兴趣的话。
&emsp;&emsp;卡夫卡写了两份遗嘱，都是给好朋友的。第一封要求所有的遗留文件都需要销毁，而时隔一年不到的时间，他就又允许了五本书和一篇短篇的存在。不知道是为什么改变了他的想法，难道是疾病？他还在想留下一些他在这个世界上活过的证据？不论如何，他真的很信任他的朋友马克斯，真是让人羡慕。
