# 卡夫卡的遗嘱
#### ——由于它们已经存在过，我不会阻止任何人得到它们，若他们有兴趣的话。
&emsp;&emsp;卡夫卡写了两份遗嘱，都是给好朋友的。第一封要求所有的遗留文件都需要销毁，而时隔一年不到的时间，他就又允许了五本书和一篇短篇的存在。不知道是为什么改变了他的想法，难道是疾病？他还在想留下一些他在这个世界上活过的证据？不论如何，他真的很信任他的朋友马克斯，真是让人羡慕。
<br/>
# 沉思
（救了个大命怎么还是献给马克斯的你们在一起得了）
## 乡间公路上的孩子们
#### ——“傻瓜怎么会累呢？”
&emsp;&emsp;好自由，好幸福，好孤独。虽然是“孩子们”，但是我总有种只有一个人在和ta想象中的朋友玩耍的感觉，ta们在沟壑间跳跃奔跑，在车道旁合唱，那为什么太阳升起的时候只能独自一人荡秋千？
<br/>
## 揭穿一个骗子
#### ——“我认出来了！”
&emsp;&emsp;这篇没怎么看懂，不太知道想表达什么。标题是揭穿一个骗子，但那个骗子无处不在，反而像是暗示主人公在与他人接触时不敢迈进的感觉，好在ta最终踏出了那一步。
<br/>
## 突如其来的散步
#### ——那么，今晚，你将彻底退出家庭，让家兀自驶向无有实存的空洞。
&emsp;&emsp;好喜欢好喜欢这篇！好畅快！无论你在“家”这个意向中扮演什么角色，只要你想，你都能坚定地站起来走开，作为一个个体，一个无可替代的个体，去往任何你想去的地方，见你想见的人。
<br/>
## 决心
#### ——简言之，就是要亲手压制住生活中如幽灵般残留的东西，好让最后的墓地般的安宁绵延下去，除此之外，别无存有。
&emsp;&emsp;虽然标题是《决心》但这股淡淡的死意是怎么回事（抹汗），卡夫卡的决心就是容忍吗？为了延绵不绝的安宁决心忍受一切，不起冲突，不去计较……好吧，让我也试试用小手指划过眉间展示一下我的决心（x
<br/>
## 山间远足
#### ——“我不知道！”
&emsp;&emsp;我在这篇极小的段落里摘抄的落脚点是第一句话：“我不知道！”山间远足，本来是一件亲近大自然，很舒心的活动，但“大家都身穿燕尾服”？“无名之辈簇拥在一起”？……啊，我也不知道了……好压抑
<br/>
## 单身汉的不幸
#### ——事情便是这样，人们都会在今天与往后的真实生活中，一具肉身连着一颗头颅站在那里，当然还有额头，你可以用手拍拍。
&emsp;&emsp;本来还有点郁闷，前面描写的完全是我的生活：一个人工作早出晚归，一个人回家领着晚饭呆呆看着天花板（啊当然我还在这里可以发发牢骚），生病了只能自己缩在床上。结果最后的最后一句，卡夫卡说我还可以拍拍自己的额头，谢谢你，我拍了。
<br/>
## 商人
#### ——“飞走吧，愿你们那双双我从未见过的翅膀，能带你们到村中山谷或者巴黎，若那里吸引着你们前去的话。”
&emsp;&emsp;这篇很好懂。生意并不怎么起色的商人忙碌了一天以后，独自一人在电梯里短暂地幻想。我想起了我的本科，上床下桌，床是被一个个遮光蚊帐包裹的，每次进入那个帐篷一样的神秘空间就好像能去到所有想去的地方，我可以感受到风吹草地拂过脸颊，也能感受到寒冬里缩在厚厚的毛毯间，还可以是海边的……早八铃声的现实是不会放过我的，电梯门也是一定会再次打开的。
<br/>
## 凭窗闲眺
#### ——但是，如果在此刻，你走到窗边，会大吃一惊地把脸颊紧贴在窗户地把手上。
&emsp;&emsp;……我很想问卡夫卡写这篇的时候是个什么心境，哪来的女子高中生……好活泼的文字……尸体都回温了。
<br/>
## 回家的路
#### ——我行进着，我的速度就是这一带街巷的速度。
&emsp;&emsp;他飘了，毫无疑问。就因为他在雨后出去走了走，就觉得自己实在是太了不起了，自己代表了一切，什么都看不上了，他飘了，在不讨人厌的范围里自恋还是有点可爱的。
<br/>
## 擦肩而过的人
#### ——说到底，难道我们不能觉得累吗？
&emsp;&emsp;好厉害的想象力，仅仅是擦肩而过，一瞬间想象出了人和人之间7种可能的关系！这，这你当然会觉得累啊……当然会不想管其他人的困难，能把自己拼凑好就已经够累了，眼不见为净的冷漠都是因为太累了。
<br/>
## 乘客
#### ——那时我自问：她怎么能不对自己感到惊讶呢？怎么能紧闭双唇，一语不发呢？
&emsp;&emsp;明明对自我的评价极低，但会惊叹他人的不可思议，要是能转换一下想法……等等，这和上上一篇《回家的路》心境正相反啊！这两种无所谓完全是两种解读啊！这两种心情会出现在同一个灵魂中，是个敏感的人哇卡夫卡。
<br/>
## 衣服
#### ——每当看得见满是褶皱、流苏及垂饰的衣服包裹着美丽的身躯，十分赏心悦目时，我就想，这些衣服不会一直这么好看下去。
&emsp;&emsp;惭愧，我每次看到街上有好看的三圈女孩的时候，隐隐地也会这么想，这么漂亮的衣服装饰，是不是也终有一天会被主人嫌弃遗忘，没有什么是永恒的，更何况是衣服这种消耗品呢。
<br/>
## 拒绝
#### ——“嗯，你我说的都对。在发现我们各自的话都无可辩驳之前，还是各回各家吧，你说呢？”
&emsp;&emsp;哈哈哈哈哈哈哈哈哈这篇真的，和现在的两性观念以及吵架方式如出一辙，一个在聊诗和远方，一个念叨床上的欢愉，你们聊不到一起的，就随那位少女说的，快各回各家吧！
<br/>
## 为男骑手们考虑
#### ——如果你仔细想想，你就不会因为诱惑而想在赛马比赛中的第一了。
&emsp;&emsp;我的第一反应竟然是：原来你们也会赌马……第一名跑得快固然开心，但也只是很短暂的成就感，若是赌马人的抱怨传进耳朵里：“怎么是你这个家伙拿了第一？！大冷门啊！”心里还是会不好受吧……
<br/>
## 临街的窗户
#### ——对于他们来说，若是没有一扇临街的窗户，是坚持不下去的。
&emsp;&emsp;漂泊的人啊，无依无靠的浮萍啊，孤独的灵魂啊，无论如何都会被烟火气吸引，这是他们还在人间的证明。
<br/>
## 真想当个印第安人
#### ——以至于你还没来得及发现眼前是一排你修整平齐的草地，马就已没入其中。
&emsp;&emsp;看到这篇的标题我就笑了，因为前面《拒绝》那篇，少女拒绝邀约的时候说：“你既非名门望族，也非魁梧的美国人——他们拥有印第安人的身材……”，他不会是因为受挫才“真想当个印第安人”吧www唉，还是幻想。
<br/>
## 树
#### ——因为我们就像躺在雪地里的树。
&emsp;&emsp;作为南方人不太有感触，倒在雪地里的树干真的推不动吗？是因为雪很松软所以沉重的树干陷进雪地里了吗？两棵树，感觉可以轻松分开，实则已紧紧相连，但也不一定。真是废话文学，不要多猜忌不就行，保持冷漠。
<br/>
## 不幸
#### ——“你的本性就是我的本性。要是我人生对你友善，你也应该这么对我。‘
&emsp;&emsp;终于有超过一页的故事了，这篇没有之前那么意识流但还是有些难懂。不幸，是主人公不幸，还是那个孩子带来了不幸？是主人公希望从孩子的到来中获得救赎但无功而返吗？应该都不是。主人公嘴上说这个孩子是鬼魂，但还是希望ta能在自己身边，即使说出来的话并没有安慰的效果，但ta的存在就足以让人欣慰，不幸的事情也终将过去，只是在最无助的时候，能有一个生命陪伴在身边，没有什么比这个更好的了。
<br/>
